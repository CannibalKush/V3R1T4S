## What n - r is here, and the complement view

Taking complements turns a 3-uniform 3-sunflower-free family on [8] into a 5-uniform family on [8] with no three members having pairwise equal unions (a "3-cosunflower-free" family). So n - r = 5.

- n - r = 2 would be Mantel's theorem (triangle-free graphs). Not this case.
- n - r = 3 is the Turan number of K4^- (three edges on four vertices), tabulated by Markstrom. That table gives g(N, N-3), so for N = 8 it gives g(8,5) = 22, not g(8,3). Not this case.
- n - r = 5: three 5-sets with common pairwise union U miss pairwise disjoint d-sets of U, so 3d is at most 5 + d, so d is 1 or 2. This is not a standard named Turan problem, and no table for it was found.
- In the original view on [8]: three pairwise disjoint 3-sets would need 9 points, so only cores of size 2 (three triples through one pair) and size 1 (three triples meeting pairwise in one common point) are forbidden. Chung-Frankl (1987) and Duke-Erdos type results handle one core size at a time for large n, not this mixed small case.
