### Per paper

- **Perminov, arXiv:2512.13365** ("Parallel Heuristic Exploration for Additive Complexity Reduction in Fast Matrix Multiplication"). It does give a count for 5x7x7, and the count is comparable: same ternary reduced convention, same rank, no basis change. The paper says it is "a parallel random-search method for reducing additive complexity in fast matrix multiplication algorithms with ternary coefficients {-1,0,1}". Its Table 1 ("Schemes with optimal rank achieving new SOTA addition counts"; columns Naive, GV, GP-5, GP-40, Prop.) has the row "5x7x7 176 2605 832 820 799 788". Its best count is 788, the same as the repository; the greedy-potential (fmm_add_reduction) best is 799. Table 6 ("Component-wise addition counts for schemes improvable by approaches result combination") lists only 4x7x8, 4x8x8, 5x7x8, 6x6x10, 7x7x7, 7x8x8 and 8x8x8, so 5x7x7 is not among the formats it lowers. 699 is below all of these.
- **Perminov, arXiv:2512.21980** (58-addition rank-23 scheme). 3x3x3 only: "achieving a rank-23 scheme with only 58 scalar additions". No 5x7x7 count.
- **Martensson and Stankovski Wagner, IACR ePrint 2026/849** ("On Why and How to Minimize the Arithmetic Complexity of Fast Matrix Multiplication Algorithms", received 2026-04-30). It uses a comparable convention: "optimizing the number of additions in Strassen-type matrix multiplication schemes for larger matrix sizes, and without any change of basis". Coverage: "use them to optimize the number of additions for schemes with dimensions up to (n, m, k) = (5, 7, 10)". **5x7x7 lies inside the range of formats this paper covers.** I could read only the abstract page; the PDF was blocked (403 challenge), so I cannot tell whether it reports a count for 5x7x7 at rank 176.
