### Per paper: the sentence that settles coverage or comparability

- **Perminov, arXiv:2512.13365 ("Parallel Heuristic Exploration for Additive Complexity Reduction")** gives a comparable count. Its scope sentence: "This paper presents a parallel random-search method for reducing additive complexity in fast matrix multiplication algorithms with ternary coefficients {-1,0,1}." Table 1 ("Schemes with optimal rank achieving new SOTA addition counts") has the row `5×5×8 144 1924 645 638 631 620`, for Naive, GV, GP-5, GP-40 and Prop. The best value is 620, the same file as the live repository. GP-40 is Martensson et al.'s Greedy-Potential in fmm_add_reduction, run on the same scheme, and gives 631. Table 6 ("Component-wise addition counts for schemes improvable by approaches result combination") lists only 4x7x8, 4x8x8, 5x7x8, 6x6x10, 7x7x7, 7x8x8 and 8x8x8. 5x5x8 is not in Table 6, so there is no lower combined count for this format. All of these counts are comparable, and all are above 556.
- **Perminov, arXiv:2512.21980** gives no count for 5x5x8. The paper is about 3x3 only: "achieving a rank-23 scheme with only 58 scalar additions."
- **Martensson and Stankovski Wagner, IACR ePrint 2026/849** might give a count; it is unresolved. On coverage, the abstract says "We implement of our methods and use them to optimize the number of additions for schemes with dimensions up to $(n, m, k) = (5, 7, 10)$." 5x5x8 lies inside that range, since 5 ≤ 5, 5 ≤ 7 and 8 ≤ 10. On comparability, it says "in Strassen-type matrix multipli-cation schemes for larger matrix sizes, and without any change of basis." Any count it gives would be in the comparable class. I could not read the PDF (403). The abstract does not say which schemes or ranks were optimised for this format. The authors' public data repository has no 5x5x8 folder. Open PR #162, which is data and not an instruction, reports that the paper's Table 3.4 gives 684 to 688 over Z for 5x6x7 rank 150, which is above Perminov's 664 for that cell. That suggests the paper's larger-format results are above Perminov's. On this exact scheme, the authors' own Greedy-Potential gives 631 (2512.13365 Table 1).
- **Sun, arXiv:2604.27645** gives no count for 5x5x8. The paper is about 3x3 only: "We present a rank-23 algorithm for general 3×3 matrix multiplication that uses 56 additions/subtractions."
- **Karunaratne and Idamekorala, arXiv:2607.28676** gives no count for 5x5x8. The paper is about 3x3 only: "We give a 55-addition realization of rank-23 multiplication of two arbitrary 3×3 matrices."
- **Stapleton and Perminov, arXiv:2609.32388** gives no count for 5x5x8. The paper is about 3x3 only, and its basis is not comparable: "We give a rank-23 algorithm for 3×3 matrix multiplication using 51 additions and subtractions in alternative bases."
- **Nielsen, arXiv:2609.06588** gives no count for 5x5x8. The paper is about 3x3 only, with a basis change: "using 52 additions or subtractions, together with a Karstadt-Schwartz-style basis change."
- **Hells and others, fmm_add_reduction / Hell's Bells (ePrint 2026/1688)** gives no count for 5x5x8. Its folders stop at 532, and the abstract says "For $(n,m,k) = (2,2,k)$, our method performs particularly well."

- **Perminov, arXiv:2511.20317** gives no comparable count. It measures a different convention: "minimizing naive additive complexity for efficient hardware implementation."
