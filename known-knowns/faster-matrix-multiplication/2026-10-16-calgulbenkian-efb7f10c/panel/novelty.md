unresolved: IACR ePrint 2026/849 full text (PDF blocked, 403 Cloudflare challenge) and the fmm_add_reduction git tree (403 rate limit). The paper uses the same convention and its stated range, up to (5, 7, 10), includes 5x6x8, so it could plausibly contain a comparable count for 5x6x8; it is not known to cover rank 170, and the authors' visible scheme folders contain no 5x6x8 input. Its own tool scored 728 on this scheme in Perminov's benchmark, so a count below 667 would need a new scheme or a much stronger reducer than the 2025 tool.
