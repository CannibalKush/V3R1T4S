## Quoted sentences settling coverage and comparability

- **Perminov arXiv:2512.13365.** The paper is comparable: same convention and same ternary coefficients. Its abstract reads: "This paper presents a parallel random-search method for reducing additive complexity in fast matrix multiplication algorithms with ternary coefficients $\{-1,0,1\}$." Table 1 row: "5×6×7 150 2039 696 691 671 664". The GP-40 column is the fmm_add_reduction tool of Mårtensson et al. ("The baseline for comparison is the fmm_add_reduction tool [2]"), so that tool reached 671 on this same scheme. Table 6 caption: "Component-wise addition counts for schemes improvable by approaches result combination". 5x6x7 is not among its rows.
- **Perminov arXiv:2512.21980.** "This paper presents a new state-of-the-art algorithm for exact $3\times3$ matrix multiplication ... achieving a rank-23 scheme with only 58 scalar additions." 3x3x3 only.
- **Mårtensson and Wagner, ePrint 2026/849.** "We present improved methods for optimizing the number of additions in Strassen-type matrix multipli- cation schemes for larger matrix sizes, and without any change of basis." and "We implement of our methods and use them to optimize the number of additions for schemes with dimensions up to $(n, m, k) = (5, 7, 10)$." Read componentwise, 5x6x7 (5 ≤ 5, 6 ≤ 7, 7 ≤ 10) **is inside the range of formats the paper covers**, and its convention (no basis change) would be comparable. The abstract does not say which schemes or ranks were treated. The authors' repository holds no 5x6x7 scheme (its largest folder is 532). The only count I could read that this tool reached on this scheme is GP-40 = 671 (Perminov's Table 1), which is above 582. Whether the PDF holds a 5x6x7 rank-150 count is unknown.
- **Mårtensson and Wagner, ePrint 2024/2063 (predecessor).** "We further provide concrete and practical implementations of our methods that are very efficient for dimensions including (and surpassing) the 666 limit, i.e. (n, m, k) = (6, 6, 6)". Its stated range is 6x6x6, and 5x6x7 has a dimension of 7.
- **Sun arXiv:2604.27645.** "We present a rank-$23$ algorithm for general $3\times3$ matrix multiplication that uses $56$ additions/subtractions". 3x3x3 only.
- **Karunaratne and Idamekorala arXiv:2607.28676.** "We give a 55-addition realization of rank-23 multiplication of two arbitrary $3\times3$ matrices." 3x3x3 only.
- **Stapleton and Perminov arXiv:2609.32388.** "We give a rank-23 algorithm for $3\times3$ matrix multiplication using 51 additions and subtractions in alternative bases." 3x3x3 only, and a basis-change count that would not be comparable anyway.
- **Nielsen arXiv:2609.06588.** "We present a rank-23 algorithm for general 3 x 3 matrix multiplication using 52 additions or subtractions, together with a Karstadt-Schwartz-style basis change". 3x3x3 only, and a basis-change count, so not comparable.
- **Kauers and Wood arXiv:2505.05896 (Lille's cited work).** "Taking these multiplication schemes as starting points, we found improved matrix multiplication schemes for various rectangular matrix formats using a flip graph search." A rank result with no addition count.
- **"Hells and others' fmm_add_reduction".** This is the werekorren repository (algorithms/hells_bells). It holds no 5x6x7 scheme or count.
