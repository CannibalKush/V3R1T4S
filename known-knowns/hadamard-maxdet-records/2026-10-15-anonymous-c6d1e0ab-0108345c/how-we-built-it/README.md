# How we built it

- `maxdet_search.c`: the original run's compiled excess search (iterated local search with basin hopping) over border sign vectors of a Hadamard core.
- `run_maxdet_campaign.py`: the original run's driver for the order-104, 108 and 116 cores.
- `PREREG.md`: the original run's pre-registration (2026-10-14T07:49:06Z), frozen before the claim was built.

This code is shipped for transparency. The claim does not depend on it.
